# Wall and Grime

Open `WallGrime.unity` after importing this sample from SimpleBlend's Package Manager Samples section. Use a URP project and assign its URP asset to Graphics and the active Quality level. The sample does not overwrite project render settings.

Select the object named `WallGrime — select to paint` and activate SimpleBlend's paint tool. The serialized paint is already initialized and remains editable.

## Layer mapping

- Unpainted: wall.
- Red: grime.
- Green: moss.
- Blue and Alpha: unused by this three-layer shader.

The source mesh has no painted colors. Per-renderer `VertexPaintData` holds the starting paint and supplies its additional vertex stream. Do not mark this renderer for static batching for the initial lesson. If the consumer project uses GPU Resident Drawer or another fallback condition, let the package's normal storage workflow select its supported mode before painting.

## Try it

1. Paint Red with radius **0.45 m**, strength **0.35**, flow **1**, accumulation on, and EaseInOut falloff.
2. Add Green in a small separate area, then inspect the channel preview.
3. Erase Red to reveal the base; Smooth a transition.
4. Undo/Redo and save the scene. Reopen it to confirm the paint survives.
5. Duplicate the painted object and repaint the duplicate. The other object and shared source mesh should remain unchanged.

These are suggested brush starting points, not a claim that the initial colors were produced by recorded strokes. Initial paint, geometry and texture patterns are procedural. The on-scene caption repeats the mapping and brush controls. Material height transition starts at 0.3; each layer's height texture has a small amplitude to keep the first lesson approachable.
